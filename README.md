# FPV

High-speed intelligent FPV drone simulation project.

## Current simulation platform

- Ubuntu 20.04
- ROS Noetic
- Gazebo Classic 11
- Flightmare
- RotorS
- Unity Flightmare Renderer

## Local workspace

This project is developed inside:

~/fpv_ws

## Start Flightmare

Run:

./scripts/run_flightmare.sh

## Project roadmap

1. Flightmare setup
2. Basic quadrotor control
3. Soft gate waypoint traversal
4. Gazebo gate visualization
5. Unity visual gate scene
6. Camera-based gate detection
7. Autonomous gate racing
